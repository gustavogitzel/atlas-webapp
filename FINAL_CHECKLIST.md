## 📞 Suporte

Se algo não funcionar:

1. **Reinstalar dependências**
   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

2. **Verificar Node.js**
   ```bash
   node --version  # Deve ser 18+
   ```

3. **Limpar cache**
   ```bash
   npm cache clean --force
   ```

4. **Reiniciar servidor**
   ```bash
   npm run dev
   ```
