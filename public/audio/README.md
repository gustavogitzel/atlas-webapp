# Background Music

This folder should contain the background music file for the application.

## Required file:
- `background-music.mp3` - Main background music track

## Recommendations:
- Format: MP3 or OGG
- Duration: 2-5 minutes (will loop automatically)
- Bitrate: 128-192 kbps (balance between quality and file size)
- Volume: Pre-normalized to avoid audio clipping
- License: Ensure you have rights to use the audio

## Suggested free music sources:
- YouTube Audio Library (free, no attribution required)
- Free Music Archive
- Incompetech (Kevin MacLeod)
- Bensound

## Current setup:
The `BackgroundMusic` component is configured to:
- Start at 30% volume
- Loop continuously
- Allow user control (play/pause, mute, volume)
- Auto-hide controls after 3 seconds
